# МАОМС “ТеРА” — Веб-сайт Асоціації

Офіційний веб-сайт Місцевої Асоціації органів місцевого самоврядування Тереблянської долини “ТеРА”. 
Проект розроблено на базі сучасного фреймворку Next.js із забезпеченням високої швидкості роботи, SEO-оптимізації та адаптивності для мобільних пристроїв.

## 🛠 Технологічний стек

- **Фронтенд:** [Next.js](https://nextjs.org/) (React фреймворк, App Router)
- **Стилізація:** [Tailwind CSS](https://tailwindcss.com/) (для адаптивного та сучасного дизайну)
- **Мова розробки:** JavaScript / TypeScript

---

## 📌 Функціонал та структура сайту

### Головні особливості:
- 📱 **Повна мобільна адаптивність** — зручний інтерфейс для смартфонів та планшетів.
- 🌐 **Мультимовність** — наявність скороченої англійської версії (інтегрована локалізація).
- 🔍 **SEO-оптимізація** — покращене індексування пошуковими роботами завдяки Server-Side Rendering (SSR).
