# МАОМС “ТеРА”

Офіційний сайт Місцевої асоціації органів місцевого самоврядування Тереблянської долини “ТеРА”.

## Технології

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Локальні шрифти Geometria

## Структура проєкту

```text
src/
  app/          маршрути Next.js App Router
  components/   UI, layout, home та page-компоненти
  content/      український та англійський контент сайту
  lib/          спільні налаштування, навігація, шрифти, images
public/
  font/         локальні шрифти
  images/       оптимізовані WebP-зображення сайту
docs/
  content-documents.md
```

## Сторінки

- Головна
- МАОМС “ТеРА”
- Члени (засновники) ТеРА
- Статутні органи
- Новини
- Кращі практики
- Конкурси і гранти
- Наші проекти
- Контакти
- Річка Теребля
